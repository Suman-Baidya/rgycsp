### 7.2 Scalability & Deployment Specifications
- **Multi-Tenant Capacity**: Supports thousands of concurrent franchise centers with zero cross-tenant data leakage.
- **Concurrent Users**: Serverless architecture automatically scales to handle tens of thousands of simultaneous students during admissions and examination cycles.
- **Device Support**: Fully responsive web design functioning seamlessly across Android smartphones, Apple iPhones/iPads, Windows laptops, and macOS computers.
- **Print Compatibility**: Built-in styling for standard PVC ID card thermal printers (CR80), POS thermal receipt printers, and desktop A4 color document printers.

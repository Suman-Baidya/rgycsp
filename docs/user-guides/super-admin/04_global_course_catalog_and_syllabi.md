## Chapter 4: Global Course Catalog & Accredited Syllabi

### 4.1 The Central Course Master
The **Global Course Master** (`/super-admin/courses`) is the single source of academic truth across ABCD Edu Hub. As Super Admin, you define the accredited programs of study taught nationwide.

---

### 4.2 Managing Course Category Groups
Before creating individual courses, organize them into recognized educational categories:
1. Navigate to **Courses** (`/super-admin/courses`).
2. Click **"Manage Course Groups"**.
3. The platform includes standard groups:
   - *Diploma Courses* (e.g., ADCA, DCA, DIT)
   - *Office & Accounting* (e.g., Tally Prime, Advanced Excel, GST)
   - *Programming & Software Development* (e.g., Python, Full-Stack Web Development)
   - *Graphic & Multimedia Design* (e.g., Photoshop, CorelDRAW, Video Editing)
   - *Vocational & Short-Term Certifications*
4. Click **"+ Add Group"** to define new categories as market demands evolve.

---

### 4.3 Creating a New Global Accredited Course (Step-by-Step)

#### Step 1: Basic Course Identity
1. In the Courses dashboard, click **"+ Add Global Course"**.
2. **Course Title**: Official accredited title (e.g., *Advanced Diploma in Computer Applications (ADCA)*).
3. **Course Code**: Unique academic identifier (e.g., *ADCA-101*).
4. **Category Group**: Assign to an established course group.
5. **Difficulty Level**: Select *Beginner*, *Intermediate*, or *Advanced*.
6. **Duration**: Specify standard completion timeline (e.g., *12 Months / 360 Hours*).

#### Step 2: Financial & Promotional Parameters
- **Recommended Base Fee (₹)**: Suggested tuition fee for affiliated franchises (e.g., `₹6,500`).
- **Display Price (Text)**: Default marketing string (e.g., `₹5,499 (Limited Time Offer)`).
- **Demand Badge**: Tag as *High Demand*, *Trending*, or *Industry Standard*.
- **Featured / Popular**: Toggle to display prominently on the main platform homepage and franchise landing pages.

#### Step 3: Accredited Syllabus Builder
Build the curriculum taught by all centers:
1. Click **"+ Add Syllabus Module"**.
2. Enter the Module Title (e.g., *Semester 1 — Module 1: Computer Hardware & Operating Systems*).
3. Add specific instructional topics:
   - *Topic 1*: Computer Architecture & Motherboard Components.
   - *Topic 2*: BIOS Configuration & Windows Installation.
   - *Topic 3*: Command Prompt & System Administration.
4. Add subsequent modules for Office Suites, Financial Accounting, Programming, and Final Project Work.

#### Step 4: Visual Banner & Publishing
1. Upload a high-resolution **Course Banner** (recommended 1200x630 pixels).
2. Click **"Publish Global Course"**.
3. **Instant Global Deployment**: The course immediately appears in every affiliated franchise's course directory, allowing local centers to activate it and start enrolling students.

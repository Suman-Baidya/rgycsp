## Chapter 8: State Manager Regional Coordinator Network

### 8.1 The Regional Governance Model
In a nationwide educational network, maintaining local accountability is vital. ABCD Edu Hub features a dedicated **State Manager Network** (`/super-admin/state-managers`) enabling regional educational coordinators to supervise franchises, foster center growth, and conduct physical audits across designated territories.

---

### 8.2 Appointing a New State Manager (Step-by-Step)
1. Navigate to **State Managers** (`/super-admin/state-managers`).
2. Click **"+ Appoint State Manager"**.
3. Fill in the coordinator's credentials:
   - **Full Name**: (e.g., *Rajesh Mukherjee*).
   - **Official Email & Mobile Number**.
   - **Assigned Territory / State**: Select primary jurisdiction (e.g., *West Bengal*, *Bihar*, *Assam*, *Odisha*).
   - **Covered Districts**: Specify all or selected districts within the state.
4. **Commission & Incentive Structure**:
   - Define coordinator commission percentages on new franchise affiliations or central merchandise sales.
5. Click **"Appoint Coordinator"**.

---

### 8.3 Regional Performance Analytics & Oversight
The State Manager console allows Super Admin to track regional efficacy:
- **Territory Center Count**: Active vs pending centers in the state.
- **Total Regional Enrollment**: Monthly student intake across all regional branches.
- **Center Audit Status**: Tracking annual physical inspections and quality compliance reports submitted by the State Manager.
